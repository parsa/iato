# CTest Integration & Ninja Build Report

## Overview

- Enabled CTest in the top-level build, registered every existing unit test
  under `tst/lib/**`, and switched the default build directory to the Ninja
  generator.
- Goal: make `ctest --output-on-failure` a single command that exercises all
  current library tests so regressions are easy to spot.

## Steps Performed

1. **Inventory**  
   - Verified the actual set of test sources by running:
     ```
     $ find tst -name 't_*.cpp'
     tst/lib/isa/t_ip.cpp
     tst/lib/isa/t_rid.cpp
     tst/lib/isa/t_cfm.cpp

     tst/lib/isa/t_bundle.cpp
     tst/lib/elf/t_args.cpp
     tst/lib/mac/t_cdirect.cpp
     ```
   - Cross-checking the CMake files confirmed it’s the same 14 executables:
     `t_ip`, `t_rid`, `t_cfm`, `t_uvr`, `t_umr`, `t_psr`, `t_bits`, `t_huge`,
     `t_real`, `t_alat`, `t_fpsr`, `t_bundle`, `t_args`, `t_cdirect`.

2. **CMake wiring**  
   - Added `enable_testing()` to the root `CMakeLists.txt`.
   - Each `tst/lib/*/CMakeLists.txt` now registers its executable with a
     directory-scoped name for clarity:
     - `tst.lib.isa.<test>` for ISA tests (`tst/lib/isa`).
     - `tst.lib.elf.<test>` for ELF tests.
     - `tst.lib.mac.<test>` for MAC tests.
   - Example snippet (ISA):
     ```cmake
     add_test(NAME tst.lib.isa.${test_target} COMMAND ${test_target})
     ```

3. **Switch build directory to Ninja**  
   - Preserved the previous Make-based build as `build.make` for reference.
   - Reconfigured `build/` with Ninja plus the existing libelf hints:
     ```
     cmake -S . -B build -G Ninja \
           -DCMAKE_BUILD_TYPE=Release \
           -DElf_INCLUDE_DIR=/home/rai_s/iato/third_party/libelf/usr/include \
           -DElf_LIBRARY=/home/rai_s/iato/third_party/libelf/usr/lib/x86_64-linux-gnu/libelf.so
     ```
   - Rebuilt everything via `cmake --build build` (Ninja backend).

4. **Run the suite**
   ```
   cd build
   ctest --output-on-failure
   ```

## Result

- CTest now knows about all 14 existing library tests.
- `cmake --build build` uses Ninja (faster incremental builds).
- `ctest --output-on-failure` completes in ~0.04s with all tests passing.
